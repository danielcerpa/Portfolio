Sobre Mí

Soy un Ingeniero de Sistemas enfocado en el desarrollo web y el análisis de datos. Me apasiona crear aplicaciones y soluciones efectivas que resuelvan problemas cotidianos en el mundo laboral.

Mis habilidades se centran en el desarrollo vanilla (HTML, CSS, JavaScript y múltiples librerías), complementándome con frameworks modernos como React y Next.js.

Para el análisis de datos me gusta trabajar con Python y su ecosistema de librerías como Pandas, NumPy, Matplotlib y DuckDB. En bases de datos trabajo con PostgreSQL y MySQL (especializándome en este último).
